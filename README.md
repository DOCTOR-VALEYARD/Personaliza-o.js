## ✦ O que é

O **Termux Studio** troca aquela tela inicial comum do Termux por uma tela sua: o **seu nome em arte** (16 estilos), o **prompt personalizado** no lugar do `$`, a **hora em vermelho** no topo, **senha de entrada** e **mensagem de boas-vindas**.

Tudo é feito por um painel profissional, com **barra de carregamento ▣▣▣▣** e **terminal sempre limpo**: cada ação apaga a anterior e mostra só ela.

Sem dependências. Só precisa do **Node.js**.

## 📦 Instalação

Cole este comando no Termux. Ele cria a pasta `DVCL-TERMUX-STUDIO`, baixa o pacote e extrai tudo lá dentro:

```bash
mkdir -p ~/DVCL-TERMUX-STUDIO && cd ~/DVCL-TERMUX-STUDIO && pkg install -y curl unzip && curl -L "https://github.com/DOCTOR-VALEYARD/Personaliza-o.js/raw/main/dvcl-termux-studio.zip" -o dvcl-termux-studio.zip && unzip -o dvcl-termux-studio.zip
```

Depois, para abrir o Studio (o instalador já instala o Node.js se faltar):

```bash
bash install.sh
```

Ou, se você já tem o Node.js:

```bash
node termux-studio.js
```

> A pasta `~/DVCL-TERMUX-STUDIO` só é usada para instalar. Depois de **Salvar e sair**, o Studio guarda uma cópia própria em `~/.dvcl_termux` e você pode abri-lo de qualquer lugar digitando `studio`.

### Atualizar

Rode o mesmo comando de instalação de novo. O `unzip -o` sobrescreve os arquivos antigos e a sua personalização continua salva.

## 🚀 Como usar

1. Digite o **nome** que vai virar arte.
2. Escolha o **estilo** (1 a 16) e a **cor**.
3. Escolha o **texto do prompt** (vai dentro de `▭❦❲ ❳❦▭`) e a cor dele.
4. No **painel**, configure senha e boas-vindas e use **[8] Visualizar**.
5. Escolha **[9] Salvar e sair**, feche o Termux e abra de novo.

Para editar depois, digite no Termux:

```bash
studio
```

## 🔐 Segurança da senha

A senha **nunca** é guardada em texto puro. O Studio grava só um *hash* **scrypt** com sal aleatório. São 3 tentativas; errou as 3, o Termux fecha.

---

## 🗂️ O que é criado no seu Termux

| Arquivo | Função |
|---------|--------|
| `~/.dvcl_termux/config.json` | Suas escolhas |
| `~/.dvcl_termux/boot.sh` | Define PS1, cores e chama a tela inicial |
| `~/.dvcl_termux/termux-studio.js` | Cópia do programa |
| `~/.dvcl_termux/bashrc.backup` | Backup do seu `.bashrc` original |
| `~/.bashrc` | Recebe um bloco marcado que carrega o `boot.sh` |
| `~/.hushlogin` | Oculta a mensagem padrão do Termux |

A personalização **fica salva** mesmo fechando o Termux. Só some se você formatar o celular, reinstalar o Termux ou restaurar pelo painel.

---

## ♻️ Restaurar o Termux original

No painel, escolha **`R`** e digite `SIM`. Isso remove o bloco do `.bashrc` e apaga a pasta `~/.dvcl_termux`.

Esqueceu a senha? Restaure o backup:

```bash
cp ~/.dvcl_termux/bashrc.backup ~/.bashrc
```

---

## ⚠️ Observações

- Funciona com **bash** (padrão do Termux).
- No texto do prompt, os caracteres `\ $ ` ' "` são removidos por segurança.
- Programas com cores próprias (`git`, `pkg`, `ls --color`) podem sobrescrever o vermelho. O Studio força vermelho no prompt, no que você digita e na saída comum.
- Nomes aceitam letras (acentos viram a letra sem acento na arte), números, espaço e `- _ . !`, até 20 caracteres.
- Em telas estreitas a arte se ajusta sozinha e, se o nome for grande, quebra em mais de uma linha.
